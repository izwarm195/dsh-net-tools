# Contributing

Thanks for your interest in dsh-net-tools!

This project is developed and maintained entirely by AI; humans review and
accept contributions.

## Development

```sh
npm install
npm test             # unit tests; network tests need a local proxy at 127.0.0.1:7897
```

## Pull requests

- Keep changes focused: one logical change per PR.
- Run `npm test` before pushing.
- Update `CHANGELOG.md` for user-visible changes.
